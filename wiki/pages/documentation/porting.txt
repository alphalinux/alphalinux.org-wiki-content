===== Porting =====

These pages describe the parts of the Alpha architecture that most often cause problems when software is first built for Alpha.

Many of these failures are latent defects in portable code rather than Alpha-specific problems. The base architecture has no byte store, no unaligned-tolerant load, no dependent-load ordering and no precise arithmetic traps, so Alpha exposes defects that x86 tolerates. Where that is the case, these pages cite the evidence that a change is a genuine fix rather than an architecture-specific workaround.

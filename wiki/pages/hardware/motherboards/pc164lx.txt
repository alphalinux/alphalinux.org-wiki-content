===== PC164LX =====

The AlphaPC 164LX is an OEM ATX form factor motherboard released in 1997.

<gallery right aligned nocrop>
wiki:hardware:motherboards:pc164lx:pc164lx-1.jpg Digital AlphaPC 164LX
</gallery>

==== Specifications ====

  * 466, 533, or 600 MHz EV56 CPU [(>{{wiki:hardware:motherboards:pc164lx:pc164lx_product_brief.pdf?linkonly|AlphaPC 164LX Motherboard Product Brief}})]
  * 2 or 4 MiB external L2 cache
  * 21174-CA chipset
  * 4x 168-pin DIMMs, supports up to 1 GiB of unbuffered ECC SDRAM
  * 2x 33 MHz 64-bit PCI slots
  * 2x 33 MHz 32-bit PCI slots
  * 2x ISA slots
  * CMD646 IDE on PCI
  * Intel 82378ZB PCI-to-ISA bridge
  * SMC FDC37C935 Super I/O controller
  * Floppy disk controller
  * PS/2 keyboard and mouse
  * 2x RS-232
  * 1x Parallel port
  * MMJ SROM console port

==== Memory ====

Memory reported to work with the 164LX (and by extension, the [[PC164SX]]):

  * Kingston KVR100X72C2/256 [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2008-May.mbox#L967|"Max. memory on 164LX"]], Juhana Helovuo, axp-list, 5 May 2008)]
  * Micron MT18LSDT1672G-10EC2 [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2008-May.mbox#L1209|"Max. memory on 164LX"]], Kazuyoshi Furutaka, axp-list, 8 May 2008)]
  * Micron MT18LSDT3272AG-10EB1

Memory reported not to work:

  * Kingston KVR133X72C3/256, due to wrong layout

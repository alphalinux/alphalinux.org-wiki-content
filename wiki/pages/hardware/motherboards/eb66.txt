The Alpha 21066 and Alpha 21068 Evaluation Board (EB66) is an evaluation board for systems based on the [[wp>Alpha_21064#Alpha_21066|Alpha 21066]] and 21068 microprocessors. [(>{{wiki:hardware:motherboards:common:windows_nt_installation_guide.pdf?linkonly|Alpha Microprocessors Motherboard Windows NT 3.51 and 4.0 Installation Guide}})] [(>{{wiki:hardware:motherboards:common:palcode_system_design_guide.pdf?linkonly|PALcode for Alpha Microprocessors System Design Guide}})] It reports system type 19 in the HWRPB. [(>{{wiki:documentation:references:alpha_axp_system_reference_manual_v6.pdf?linkonly|Alpha AXP System Reference Manual, Version 6 (1994)}})]

The EB66 was Digital's first AT form factor Alpha motherboard, and the Noname (AXPpci 33) is based on revision 1 of its design. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1996-September.mbox#L3730|"Re: interesting benchmarks"]], David A Rusling, axp-list, 4 Sep 1996)] The [[hardware:motherboards:eb66plus|EB66+]] is the corresponding board for the 21066A.

==== Specifications ====

  * [[wp>Alpha_21064#Alpha_21066|21066]] (LCA4) CPU; Digital's 21066 evaluation kit, available from late 1993, contained an example motherboard with a 166 MHz 21066, 32 MiB of memory, PCI and ISA, and embedded NCR SCSI [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/comp-sys-dec-mbox/googlegroups-1993-November.mbox#L3162|"Re: Likely price of 21066, 21064 systems?"]], Stephen Hoffman, comp.sys.dec, 29 Nov 1993)]
  * Memory controller, cache controller, and PCI bus integrated into the CPU, which supports up to 512 MiB of DRAM and 2 MiB of cache [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/comp-sys-dec-mbox/googlegroups-1993-November.mbox#L3162|"Re: Likely price of 21066, 21064 systems?"]], Stephen Hoffman, comp.sys.dec, 29 Nov 1993)]
  * I/O subsystem identical to the [[hardware:motherboards:eb64plus|EB64+]]'s: 3 ISA and 2 PCI slots (one pair shared), NCR 53C810 SCSI and Digital 21040 Ethernet on PCI, an Intel SaturnI/O PCI-to-ISA bridge, a Super I/O controller with 2 serial ports, a parallel port, and a floppy controller, PS/2 style keyboard and mouse, and RTC/NVRAM [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/Kconfig?h=v6.9|arch/alpha/Kconfig]], Linux 6.9)]
  * Baby AT size, running from a standard PC power supply [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/Kconfig?h=v6.9|arch/alpha/Kconfig]], Linux 6.9)]

==== Firmware ====

The EB66 runs the Windows NT ARC firmware, which resides in a UVPROM. DEC did not supply updated firmware in a UVPROM; to update it, the user programs a UVPROM, replaces one of the UVPROMs on the board, and selects it with the UVPROM select jumper. [(>{{wiki:hardware:motherboards:common:windows_nt_installation_guide.pdf?linkonly|Alpha Microprocessors Motherboard Windows NT 3.51 and 4.0 Installation Guide}})]

DEC also distributed SRM consoles for the EB66, along with its other evaluation boards, as part of its evaluation board software development kit. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1998-January.mbox#L3642|"Re: SRM license issues"]], Jay Estabrook, axp-list, 6 Jan 1998)]

==== Linux ====

Linux 6.9 was the last version to support the EB66; Linux 6.10 removed support for processors older than the EV56 (21164A). [(>[[https://git.kernel.org/torvalds/c/a4184174be36|"alpha: drop pre-EV56 support"]], Linux 6.10)] Kernels up to 6.9 support it with ''CONFIG_ALPHA_EB66'' or a generic kernel. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/Kconfig?h=v6.9|arch/alpha/Kconfig]], Linux 6.9)] The MILO image is named ''eb66''. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1998-March.mbox#L30004|"Re: AlphaServer 800"]], Jay Estabrook, axp-list, 25 Mar 1998)]

In kernels up to 6.9, the onboard devices listed in the kernel's description of the board use these drivers:
  * SCSI (NCR 53C810): ''sym53c8xx''. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/scsi/sym53c8xx_2/sym_glue.c?h=v6.9|drivers/scsi/sym53c8xx_2/sym_glue.c]], Linux 6.9)]
  * Ethernet (DECchip 21040): ''de2104x''; the ''tulip'' driver does not list the 21040's PCI ID. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/net/ethernet/dec/tulip/de2104x.c?h=v6.9|drivers/net/ethernet/dec/tulip/de2104x.c]], Linux 6.9)] [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/net/ethernet/dec/tulip/tulip_core.c?h=v6.9|drivers/net/ethernet/dec/tulip/tulip_core.c]], Linux 6.9)]
  * Serial ports: ''8250'', at the standard PC addresses listed in the Alpha serial port table. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/include/asm/serial.h?h=v6.9|arch/alpha/include/asm/serial.h]], Linux 6.9)]
  * Parallel port: ''parport_pc''; floppy: ''floppy''; keyboard and mouse: ''i8042''. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/parport/parport_pc.c?h=v6.9|drivers/parport/parport_pc.c]], Linux 6.9)] [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/block/floppy.c?h=v6.9|drivers/block/floppy.c]], Linux 6.9)] [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/input/serio/i8042.c?h=v6.9|drivers/input/serio/i8042.c]], Linux 6.9)]

Many mailing list posts use "EB66" to refer to the [[hardware:motherboards:eb66plus|EB66+]], so reports of a given "EB66" do not necessarily apply to this board.

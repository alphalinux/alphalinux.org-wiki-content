===== UP2000 / UP2000+ =====

The UP2000 and UP2000+ are motherboards produced by API NetWorks which featured the Tsunami chipset and a Slot B processor interface.

==== UP2000 ====

The UP2000 is the first motherboard to be built by API NetWorks and was released in 1999.

  * 1-2 667 MHz EV67 CPUs with 2/4 MiB external L2 cache or 750 MHz EV67 CPUs with 4/8 MiB external L2 cache [(>{{wiki:hardware:motherboards:up2000:up2000_user_manual.pdf?linkonly|UP2000 User Manual}})]
  * Tsunami chipset (1x Cchip, 4x Dchips, 2x Pchips)
  * 8x 168 pin DIMMs, supports 64 MiB to 2 GiB of ECC Registered RAM (2.67 GiB/s)
  * 256-bit memory bus running at 83 MHz
  * 64-bit 33 MHz PCI Bus with 2x 64-bit 33 MHz PCI slots and 1 32-bit 33 MHz slot
  * 32-bit 33 MHz PCI Bus with 3x PCI slots
  * AIC-7891 SCSI

==== UP2000+ ====

The UP2000+ is a minor update to the UP2000. It contains only a few changes, noted below. Otherwise, all the hardware is the same.

A feature added to the UP2000+ was the ability to automatically detect the frequency of the CPUs, whereas the UP2000 required jumpered configuration. [(>[[https://www.theregister.com/on-prem/2000/09/15/api-messes-up-alpha-mobo-upgrade/1545403|"API messes up Alpha mobo upgrade"]], Mike Magee, The Register, 15 Sept 2000)]
  * 1-2 833 MHz EV68AL CPUs with 4/8 MiB external L2 cache (in addition to CPUs supported by UP2000) [(>{{wiki:hardware:motherboards:up2000plus:up2000plus_user_manual.pdf?linkonly|UP2000+ User Manual}})]
  * 2x 64-bit 33 MHz PCI Buses
    * 3x 64-bit Slots on bus 0
    * 1x 64-bit and 2x 32-bit slots on bus 1

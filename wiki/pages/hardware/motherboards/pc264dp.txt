The AlphaPC 264DP is a dual-processor motherboard based on the Alpha 21264 microprocessor and the 21272 core logic chipset. The CPUs and their L2 cache are on daughtercards that plug into the mainboard. Its Linux platform name is DP264, and the AlphaServer DS20 is based on the same design.

==== Specifications ====

  * 1 or 2 daughtercards, each with a 500 MHz Alpha 21264 CPU and 2 MiB L2 cache [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}})]; the board supports 2 or 4 MiB, the same size on both cards [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_technical_reference_manual.pdf?linkonly|AlphaPC 264DP Technical Reference Manual}}, p. 1-4)]
  * 21272 core logic chipset (1 Cchip, 8 Dchips, 2 Pchips)
  * 16x 200-pin buffered DIMMs (four arrays of four), supports 128 MiB to 4 GiB of ECC SDRAM
  * 2x 33 MHz 64-bit PCI buses
  * 6x 64-bit PCI slots (one shared with ISA)
  * 1x ISA slot (shared with PCI)
  * Cypress CY82C693UB PCI-to-ISA bridge, IDE, keyboard, mouse, and time-of-year clock
  * CR2032 coin cell (XB1) for the real-time clock [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}}, p. 2-4)]
  * Adaptec AIC-7895 dual-port Ultra Wide SCSI controller
  * SMC FDC37C669 Super I/O controller (floppy, 2x serial, parallel)
  * Mainboard dimensions: 42.11 cm x 33.02 cm (16.58 in x 13.0 in)
  * AlphaBIOS and SRM console firmware

Production boards set the configuration with switchpacks SW2 and SW3 on the mainboard and SW2 on each daughtercard; the daughtercard switches set the CPU core voltage and the flash ROM selection. [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}}, pp. 3-1 to 3-2)] The user-settable mainboard switches are: [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}}, pp. 3-1 to 3-3)]

^ Switch ^ Off (default) ^ On ^
| SW2-1 (fsb) | Normal boot | Fail-safe booter |
| SW2-4 (mdb) | Normal SROM flow | SROM enters the Mini-Debugger |
| SW2-8 (pby) | Normal operation | Bypass and clear the AlphaBIOS password |
| SW3-8 (flash_wr) | Flash ROM writable | Flash ROM write-protected (the board does not run) |

SW2-2 and SW2-3 must stay off, SW2-5 to SW2-7 must stay at the 83.3 MHz 21272 setting (off, on, on for sp2, sp1, sp0), and SW3-1 to SW3-7 must stay at their reserved settings. [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}}, pp. 3-1 to 3-2)]

The three PCI slots nearest the DIMMs are on PCI bus 0, and the three nearest the board edge are on PCI bus 1, where a VGA card is not expected to work. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L3004|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)] [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2858|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)] ATI Rage 128 and Radeon cards work in a DP264 with SRM 5.8 and later. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2790|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)]

==== CPU ====

  * The original daughtercards carry 500 MHz 21264 (EV6) CPUs with 2 MiB of cache; the DS20's 500 MHz modules have 4 MiB (see [[hardware:cpus#dp264_ds20_ds20e|CPUs]]). Compaq offered no official CPU upgrades for the DS20 or 264DP [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L9563|"Re: Upgrade paths"]], Jay Estabrook, axp-list, 16 Aug 2000)], but vendors selling API products offered 667 MHz daughtercards with 4 MiB cache. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L10574|"Re: Upgrade paths"]], Maurice Hilarius, axp-list, 16 Aug 2000)] [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L10449|"Re: Upgrade paths"]], Iwao Makino, axp-list, 17 Aug 2000)]
  * DS20E daughtercards are expected to work in a 264DP, but that configuration was not supported by Compaq. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L9563|"Re: Upgrade paths"]], Jay Estabrook, axp-list, 16 Aug 2000)] AlphaServer ES40 CPU daughtercards do not fit. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2002-October.mbox#L12881|"Re: DP264 Processor Modules"]], Jay Estabrook, axp-list, 21 Oct 2002)]
  * The CPU is soldered to the daughtercard, so replacing it with a faster CPU is not practical. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2003-February.mbox#L6127|"Re: 264DP cpu installation"]], Jay Estabrook, axp-list, 12 Feb 2003)] A different CPU would also require matching SROM code. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2003-February.mbox#L7871|"Re: 264DP cpu installation"]], Rich Payne, axp-list, 11 Mar 2003)]

==== Memory ====

With 256 MiB DIMMs, the largest available when the board was introduced, the 16 DIMM slots hold 4 GiB. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-March.mbox#L30767|"Re: > 1GB on alpha.  Patch to 1TB?"]], Maurice Hilarius, axp-list, 11 Mar 1999)] 512 MiB DIMMs are reported not to work in the DP264. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2001-April.mbox#L6538|"Re: DS10 or XP100"]], Rich Payne, axp-list, 6 Apr 2001)]

==== Firmware ====

The 264DP is essentially the same board as the AlphaServer DS20, [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-April.mbox#L22011|"Re: DP264 sdk debugger on DS20"]], Rich Payne, axp-list, 25 Apr 2000)] while the DS20E has some differences. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2000-November.mbox#L2869|"Re: Hosed DSP264 system"]], Rich Payne, axp-list, 2 Nov 2000)] Its SRM firmware came from Compaq, including copies distributed by API. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2752|"Re: ATI Rage 128 and UP2000/264DP board"]], Rich Payne, debian-alpha, 7 Aug 2001)] See [[hardware:systems:goldrush|AlphaServer DS20]] for the DS20 itself.

API's copies of the 264DP firmware are kept in the [[https://github.com/alphalinux/firmware/tree/master/api/DP|alphalinux/firmware]] repository: the SRM image ''pc264srm.rom'', the AlphaBIOS image ''Pc264nt.sys'', and an earlier package, dated August 2000, in ''archive/5.8''. The update is run with ''lfu'' from two floppies, using ''pc264fw.txt'' as the file list. [(>[[https://github.com/alphalinux/firmware/blob/master/api/DP/floppy_readme.txt|floppy_readme.txt]], alphalinux/firmware repository)]

  * Early SRM versions did not initialize large amounts of memory correctly when ''os_type'' was set to UNIX; upgrading SRM fixes it. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-July.mbox#L34879|"Re: DS20 fail with 1G memory...."]], Rich Payne, axp-list, 27 Jul 1999)] [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-July.mbox#L35139|"Re: DS20 fail with 1G memory...."]], Xiaozhou Qiu, axp-list, 27 Jul 1999)]
  * The console prompt shows which CPU is running the console (''%%P00>>>%%'' for CPU 0). Linux must be booted from CPU 0. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-May.mbox#L30756|"Re: DP264 Kernels...."]], Jay Estabrook, axp-list, 13 May 1999)]

==== Linux ====

Current kernels support the AlphaPC 264DP with ''CONFIG_ALPHA_DP264'' or a generic kernel, including both CPUs in SMP kernels; [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_dp264.c?h=v7.3-rc1|arch/alpha/kernel/sys_dp264.c]], Linux 7.3)] it boots from SRM with [[software:boot_loaders:aboot|aboot]]. There is no MILO for the board. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1998-November.mbox#L4314|"Re: milo for dp264?"]], Jay Estabrook, axp-list, 3 Nov 1998)] [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-June.mbox#L26765|"RE: Milo for dp264 ?"]], James Livingston, axp-list, 21 Jun 1999)] The onboard AIC-7895 SCSI controller uses the ''aic7xxx'' driver, [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/scsi/aic7xxx/aic7xxx_pci.c?h=v7.3-rc1|drivers/scsi/aic7xxx/aic7xxx_pci.c]], Linux 7.3)] and the Cypress IDE controller ''pata_cypress''. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/ata/pata_cypress.c?h=v7.3-rc1|drivers/ata/pata_cypress.c]], Linux 7.3)]

===== PC264DP =====

The AlphaPC 264DP is a dual-processor motherboard based on the Alpha 21264 microprocessor and the 21272 core logic chipset. The CPUs and their L2 cache are on daughtercards that plug into the mainboard. Its Linux platform name is DP264, and the AlphaServer DS20 is based on the same design.

==== Specifications ====

  * 1 or 2 daughtercards, each with a 500 MHz Alpha 21264 CPU and 2 MiB L2 cache [(>{{wiki:hardware:motherboards:pc264dp:pc264dp_user_manual.pdf?linkonly|AlphaPC 264DP User's Manual}})]
  * 21272 core logic chipset (1 Cchip, 8 Dchips, 2 Pchips)
  * 16x 200-pin buffered DIMMs (four arrays of four), supports 128 MiB to 4 GiB of ECC SDRAM
  * 2x 33 MHz 64-bit PCI buses
  * 6x 64-bit PCI slots (one shared with ISA)
  * 1x ISA slot (shared with PCI)
  * Cypress CY82C693UB PCI-to-ISA bridge, IDE, keyboard, mouse, and time-of-year clock
  * Adaptec AIC-7895 dual-port Ultra Wide SCSI controller
  * SMC FDC37C669 Super I/O controller (floppy, 2x serial, parallel)
  * Mainboard dimensions: 42.11 cm x 33.02 cm (16.58 in x 13.0 in)
  * AlphaBIOS and SRM console firmware

The photos labeled DS20 show a Digital 54-24756-02 AlphaServer DS20 system board. It has the same layout and components as the AlphaPC 264DP described above: 16 DIMM slots, 6 PCI slots plus 1 ISA slot, two daughtercard connectors, and the AIC-7895 and CY82C693UB chips. The CPU card photos show daughtercards built by DEC and by Samsung.

==== Firmware and booting Linux ====

Linux on the 264DP boots from the SRM console with ''aboot''. There is no MILO for the board. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1998-November.mbox#L4314|"Re: milo for dp264?"]], Jay Estabrook, axp-list, 3 Nov 1998)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-June.mbox#L26765|"RE: Milo for dp264 ?"]], James Livingston, axp-list, 21 Jun 1999)]

  * Early SRM versions did not initialize large amounts of memory correctly when ''os_type'' was set to UNIX. Setting ''os_type'' to OpenVMS works around it, since ''aboot'' switches to the OSF/1 PALcode anyway. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-May.mbox#L29770|"Re: DP264 Kernels...."]], Thomas Leitner, axp-list, 13 May 1999)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-May.mbox#L33206|"Re: DP264 Kernels...."]], Richard Henderson, axp-list, 14 May 1999)] Upgrading SRM also fixes it. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-July.mbox#L34879|"Re: DS20 fail with 1G memory...."]], Rich Payne, axp-list, 27 Jul 1999)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-July.mbox#L35139|"Re: DS20 fail with 1G memory...."]], Xiaozhou Qiu, axp-list, 27 Jul 1999)]
  * The console prompt shows which CPU is running the console (''P00>>>'' for CPU 0). Linux must be booted from CPU 0, and all interrupts are routed to CPU 0. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-May.mbox#L30756|"Re: DP264 Kernels...."]], Jay Estabrook, axp-list, 13 May 1999)]

==== AlphaServer DS20 ====

The 264DP is essentially the same board as the AlphaServer DS20 [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-April.mbox#L22011|"Re: DP264 sdk debugger on DS20"]], Rich Payne, axp-list, 25 Apr 2000)], while the DS20E has some differences. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-November.mbox#L2869|"Re: Hosed DSP264 system"]], Rich Payne, axp-list, 2 Nov 2000)] SRM firmware for the DP264 came from Compaq, including copies distributed by API. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2752|"Re: ATI Rage 128 and UP2000/264DP board"]], Rich Payne, debian-alpha, 7 Aug 2001)]

==== CPU daughtercards ====

  * The original daughtercards carry 500 MHz 21264 (EV6) CPUs. Compaq offered no official CPU upgrades for the DS20 or 264DP [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L9563|"Re: Upgrade paths"]], Jay Estabrook, axp-list, 16 Aug 2000)], but vendors selling API products offered 667 MHz daughtercards with 4 MiB cache. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L10574|"Re: Upgrade paths"]], Maurice Hilarius, axp-list, 16 Aug 2000)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L10449|"Re: Upgrade paths"]], Iwao Makino, axp-list, 17 Aug 2000)]
  * DS20E daughtercards will probably work in a 264DP, but that configuration was not supported by Compaq. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-August.mbox#L9563|"Re: Upgrade paths"]], Jay Estabrook, axp-list, 16 Aug 2000)] AlphaServer ES40 CPU daughtercards do not fit. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2002-October.mbox#L12881|"Re: DP264 Processor Modules"]], Jay Estabrook, axp-list, 21 Oct 2002)]
  * The CPU is soldered to the daughtercard, so replacing it with a faster CPU is not practical. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2003-February.mbox#L6127|"Re: 264DP cpu installation"]], Jay Estabrook, axp-list, 12 Feb 2003)] A different CPU would also require matching SROM code. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2003-February.mbox#L7871|"Re: 264DP cpu installation"]], Rich Payne, axp-list, 11 Mar 2003)]

==== Memory ====

With 256 MiB DIMMs, the largest available when the board was introduced, the 16 DIMM slots hold 4 GiB. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-March.mbox#L30767|"Re: > 1GB on alpha.  Patch to 1TB?"]], Maurice Hilarius, axp-list, 11 Mar 1999)] Rich Payne recalled that 512 MiB DIMMs did not work in the DP264. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2001-April.mbox#L6538|"Re: DS10 or XP100"]], Rich Payne, axp-list, 6 Apr 2001)]

==== PCI slots ====

All six PCI slots are 64-bit. The three slots nearest the DIMMs are on PCI bus 0, and the three nearest the board edge are on PCI bus 1, where a VGA card is not expected to work. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L3004|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2858|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)] Jay Estabrook ran ATI Rage 128 and Radeon cards in a DP264 with SRM 5.8 and later. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2001-August.mbox#L2790|"Re: ATI Rage 128 and UP2000/264DP board"]], Jay Estabrook, debian-alpha, 7 Aug 2001)]

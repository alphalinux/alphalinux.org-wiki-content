==== Form factor, firmware, and Linux ====

All boards also have PS/2 keyboard and mouse ports. The firmware column lists the consoles available for each board, with the last SRM version where it is known; "or" marks boards whose flash holds only one console at a time.

Boards with EV4, EV45, LCA, or EV5 processors are not supported by Linux 6.10 or later, which requires an EV56 (21164A) or later processor; Linux 6.9 was the last version to support them. [(>[[https://git.kernel.org/torvalds/c/a4184174be36|"alpha: drop pre-EV56 support"]], Linux 6.10)] The current kernel column uses these values:
  * **Supported**: current kernels support the board.
  * **Untested**: the support code is in current kernels, but no one has reported booting a current kernel, or there is a specific doubt, such as a board that only MILO can boot.
  * **Linux 6.9 and earlier**: the board has a processor older than the EV56 (21164A).
  * **Removed in //year//**: support was removed before Linux 6.10 for another reason.
  * **Never**: Linux never supported the board.

The AlphaPC 164UX and 164RX can only boot Linux through [[software:boot_loaders:milo|MILO]].

Details and sources are on each board's page.

The EB64+, EB66+, EB164, AXPpci 33, and AlphaPC 64 keep the time in a Dallas DS1287 or DS1287A clock chip that contains a sealed lithium cell, so the whole chip is replaced when the cell is exhausted; the AlphaPC 164, 164LX, 164SX, and 264DP use a replaceable CR2032 coin cell. Details and sources are on each board's page; see also [[hardware:systems#common_problems|Systems: Common problems]].

API NetWorks also announced the [[hardware:motherboards:up1700|UP1700]] and [[hardware:motherboards:up2700|UP2700]] for 2001, but neither was released.

Digital's VMEbus single-board computers are on the [[hardware:motherboards:alpha_vme|AXPvme and Alpha VME]] page.

See also [[hardware:chipsets|Chipsets]].

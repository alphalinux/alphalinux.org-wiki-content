See also [[hardware:chipsets|Chipsets]].

==== Linux support ====

Since Linux 6.10, released in July 2024, the kernel requires an EV56 (21164A) or later processor, because it needs the byte/word extension (BWX) to make byte and word stores atomic. [(>[[https://git.kernel.org/torvalds/c/a4184174be36|"alpha: drop pre-EV56 support"]], Linux 6.10)] Current kernels therefore support the EV56 (21164A), the PCA56 and PCA57 (21164PC), all 21264 variants (EV6, EV67, EV68), and the EV7 (21364). The EV4 and EV45 (21064 and 21064A), the LCA4 and LCA45 (21066, 21066A, 21068, and 21068A), and the EV5 (21164) need Linux 6.9 or earlier.

==== Names and type codes ====

The consoles report processors by part number rather than by EV name, for example "Alpha 21264A-8 666 MHz" on a DS20E, so the EV name has to be looked up from the part number. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/2000-January.mbox#L16570|"SUMMARY: cpu EV revision?"]], Kim Roy, tru64-unix-managers, 13 Jan 2000)] The table maps the processor type codes in Tru64 UNIX's ''cpuconf.h'' to part numbers and EV names, [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/2000-March.mbox#L6483|"Displaying system model ID string"]], Alan Davis, tru64-unix-managers, 16 Mar 2000)] and gives the GCC ''-mcpu'' value for each. GCC has no separate value for the EV68, which adds no instructions to the EV67, or for the PCA57, which uses ''pca56''. [(>[[https://gcc.gnu.org/git/?p=gcc.git;a=blob;f=gcc/config/alpha/alpha.cc|gcc/config/alpha/alpha.cc]], GCC)]

==== Performance notes ====

Alpha has no integer divide instruction; division is a library routine, so division-heavy code runs slowly. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/comp-unix-osf-misc-mbox/googlegroups-1994-January.mbox#L2040|"Re: Optimization on ALPHA OSF1 ??"]], Burkhard Neidecker-Lutz, comp.unix.osf.misc, 27 Jan 1994)]

==== History ====

The 21164 was announced on 7 September 1994 in 266 MHz and 300 MHz versions, as the first Alpha with two levels of on-chip cache. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/biz-digital-announce-mbox/googlegroups-1994-September.mbox#L855|"Press/Digital Microprocessor Posts World Record"]], Digital Press and Analysts News, biz.digital.announce, 7 Sep 1994)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/biz-digital-articles-mbox/googlegroups-1994-September.mbox#L7010|"Alpha AXP 21164 Microprocessor -- The World's Fastest Chip"]], Customer Update, biz.digital.articles, 23 Sep 1994)] Faster parts followed, reaching 600 MHz from Digital on 31 March 1997, alongside the ATX form factor [[hardware:motherboards:pc164lx|AlphaPC 164LX]] motherboard; Samsung later sold 633 MHz and 667 MHz parts. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/biz-digital-announce-mbox/googlegroups-1997-April.mbox#L1|"Press/Alpha 21164 Microprocessor Streaks to 600MHz, Sets New Records"]], Digital Press and Analysts News, biz.digital.announce, 2 Apr 1997)]

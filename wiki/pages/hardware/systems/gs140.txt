===== AlphaServer GS60, GS60E, and GS140 =====

The AlphaServer GS60, GS60E, and GS140 are [[hardware:systems:turbolaser|AlphaServer 8200 and 8400]] systems with 21264 CPUs, "2-6 (GS60) or 2-14 (GS140) Alpha 21264 CPU processors". [(>{{wiki:hardware:systems:alphaserver_gs60:alphaserver_gs60_gs140_product_profile.pdf?linkonly|AlphaServer GS60 and GS140 Series with Alpha 21264 Processor}}, Product Profile, Compaq, June 1999)] An AlphaServer 8200 could be upgraded to a GS60 and an 8400 to a GS140. [(>{{wiki:hardware:systems:alphaserver_8400:alphaserver_8200_8400_dec_7000_upgrades_catalog.pdf?linkonly|Compaq AlphaServer 8200/8400 and VAX/DEC 7000 Upgrades}}, Systems and Options Catalog, June 1999, p. 2.211)] The three share one firmware kit, built for the E2063-DA and E2067-DA CPU modules, which "cannot be used with AlphServer 8200/8400 systems". [(>{{wiki:software:firmware:alphaserver_gs140_v6.6_firmware_release_notes.pdf?linkonly|AlphaServer GS60/GS60E/GS140 V6.6 Firmware Update Procedures}}, p. 1-1)]

==== Specifications ====

Except where noted, the following comes from the product profile. [(>{{wiki:hardware:systems:alphaserver_gs60:alphaserver_gs60_gs140_product_profile.pdf?linkonly|AlphaServer GS60 and GS140 Series with Alpha 21264 Processor}}, Product Profile, Compaq, June 1999)]

  * Two to six [[wp>Alpha_21264|21264]] CPUs in the GS60 and two to 14 in the GS140, each with 4 MiB of ECC protected onboard cache; the GS60 was sold as the 6/525 model [(>{{wiki:hardware:systems:alphaserver_gs60:alphaserver_gs60_8200_tru64_openvms_systems_catalog.pdf?linkonly|Compaq AlphaServer GS60 and AlphaServer 8200 Tru64 UNIX and OpenVMS Systems}}, Systems and Options Catalog, April 1999, p. 2.1)]
  * Up to 12 GiB of memory in the GS60 and 28 GiB in the GS140
  * Up to 132 PCI slots in the GS60 and 144 in the GS140, on an I/O architecture with multiple high-speed channels for PCI, EISA, or XMI
  * Integral UltraSCSI (40 MB/s) adapter for internal and external storage
  * 40 or 48 internal storage slots, up to 720 GB of internal storage in the GS60 and 864 GB in the GS140
  * Hot swap disks, RAID, N+1 redundant power supplies, ECC memory, heat, fan, and power supply sensors
  * Tru64 UNIX and OpenVMS only; Windows NT was promised but never shipped

==== Upgrades ====

An 8200 or 8400 upgraded with EV6 CPU modules had to have its operating system moved to Digital UNIX V4.0E first, since V4.0D cannot run on the 21264. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/1998-December.mbox#L5713|"[SUMMARY]: Is 4.0e REQUIRED for EV6?"]], Mohan, alpha-osf-managers, 21 Dec 1998)] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/2000-March.mbox#L995|"SUMMARY: AS8200 -> GS60 upgrade:  Which comes first,"]], John Losey, tru64-unix-managers, 23 Mar 2000)] Upgrades used dual-CPU modules, such as one dual 500 MHz EV6 module replacing two EV56 625 MHz modules, and several owners reported doing it without changing the backplane. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/2000-April.mbox#L10203|"Summary EV67 processors in a AS840"]], Gwen Pettigrew, tru64-unix-managers, 17 Apr 2000)] EV67 modules at 667 and 700 MHz were also fitted to 8200s. On one 8200 converted from Windows NT, field service had to change the backplane firmware because "the system would freeze during power-up unless you hit the reset switch manually (a timing issue)". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/tru64-unix-managers-mbox/2001-January.mbox#L15639|"SUMMARY: 8200 to GS60 Conversion."]], Paul Roetman, tru64-unix-managers, 12 Jan 2001)]

==== GS60E restrictions ====

Compaq's release notes for the GS60E give the KN7CG 6/525 CPU module (E2063) as needing Tru64 UNIX V4.0E, OpenVMS V7.1-2, and SRM console V5.5-12, with Windows NT "not supported". The Ethernet connector on the KFE72 standard I/O module is not supported even though "the console display indicates this device in response to a show device and show network commands"; the KZPAA PCI SCSI adapter "has been qualified only for use with the CD-ROM device"; BA350 shelves are not supported in either cabinet; and "No EISA options are supported on GS60E systems." [(>{{wiki:hardware:systems:alphaserver_gs60:alphaserver_gs60e_release_notes.pdf?linkonly|AlphaServer GS60E Release Notes}}, EK-GS60E-RN.A01, August 1999, p. 1)]

Two halt conditions get special handling, the double-error halt (halt code 06) and a machine check taken in PAL mode (halt code 07). After either one "continued system operation is not possible", and because the hardware error state cannot be collected the usual way, there may be no error log entry or memory dump at all. Instead the console and PALcode write a halt frame into a nonvolatile area of each CPU module's EEPROM, read back with ''show eeprom halt'' on every CPU module and cleared with ''clear eeprom halt''. Console V5.5-12 keeps two frames per CPU, after which the area must be reinitialized before further events are saved. The frames are timestamped from the CPU's watch chip, whose year register counts from 1900 under OpenVMS and from 1952 under Tru64 UNIX; only the primary CPU keeps system time, so "the timestamp contained within the halt frame for a secondary CPU should NOT be used to determine the time of occurrence." [(>{{wiki:hardware:systems:alphaserver_gs60:alphaserver_gs60e_release_notes.pdf?linkonly|AlphaServer GS60E Release Notes}}, p. 2)]

==== Linux ====

Linux does not run on them. An 8400 upgraded to a GS140 loaded a kernel from aboot, but "It's HALT:ing right after it's trying to start the kernel." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2003-September.mbox#L12103|"Re: AlphaServer GS140 (8400)"]], Pasi Pirhonen, debian-alpha, 24 Sep 2003)] Alpha Core 3 on a GS60 "drew a bunch of gibberish on the screen and locked up". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2008-February.mbox#L341|"GS60 available for porting"]], Adrian Looker, axp-list, 18 Feb 2008)]

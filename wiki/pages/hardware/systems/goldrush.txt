===== AlphaServer DS20 and DS20E (Goldrush) =====

"DS20 == DP264 == GOLDRUSH (1 or 2 CPUs on daughtercards, 2 PCI buses)". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-March.mbox#L24945|"FAQ info (was Re: Linux on Compaq XP1000)"]], Jay Estabrook, axp-list, 9 Mar 1999)] The system is the Compaq product built from the same design as the [[hardware:motherboards:pc264dp|AlphaPC 264DP]], sold as a pedestal that also fits M-series cabinets. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20_windows_nt_catalog.pdf?linkonly|AlphaServer DS20 Windows NT}}, Systems and Options Catalog, June 1999, p. 2.45)]

==== Specifications ====

Except where noted, the following comes from the Windows NT catalog. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20_windows_nt_catalog.pdf?linkonly|AlphaServer DS20 Windows NT}}, Systems and Options Catalog, June 1999, pp. 2.45-2.47)]

  * One or two 500 MHz [[wp>Alpha_21264|21264]] CPUs with 4 MB of level 2 cache, on daughtercards
  * 21272 (Tsunami) core logic with two PCI buses
  * "Five 64-bit PCI slots and one 64-bit PCI/ISA combination slot", and "16 DIMM memory slots"
  * Memory in kits of four industry-standard ECC DIMMs, up to four kits for 4 GB; kits of 128 MB, 256 MB, 512 MB, and 1 GB
  * Onboard diskette controller, two serial ports, one parallel port, keyboard and mouse controller; SCSI and Ethernet are PCI options
  * Ten internal storage slots: floppy, CD-ROM, one further 5.25-inch removable media bay, and seven hot swap StorageWorks disks, up to 128 GB with 18.2 GB disks
  * Hot swap disks, redundant power supplies, ECC memory, heat, fan, and power supply sensors

The console and kernel identify Tsunami family machines by a variation name; a DS20E reports Catamaran: "Booting GENERIC on Tsunami variation Catamaran using machine vector DP264 from SRM". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/comp-os-linux-alpha-mbox/googlegroups-2000-May.mbox#L16600|"linux does not find second cpu on DS20E"]], Wayne Hall, comp.os.linux.alpha, 15 May 2000)] The same line appears in the Linux boot log Compaq printed in the DS20E reference guide. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, p. 4-21)]

=== AlphaServer and AlphaStation DS20E ===

The DS20E is a separate design from the DS20, sold as a pedestal or a rackmount system. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, ER-K8F6W-UA.D01, pp. 1-3 to 1-7)]

  * Up to two 21264 CPUs; upgrade kits were KN310 for 500 MHz and KN311 for 667 MHz, in per-operating-system variants, of which the -BD suffix is the Linux one. Dual processors must match in speed and cache size [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, p. 5-10)]
  * Up to 16 200-pin DIMMs in four banks of four, populated in numerical order with four identical DIMMs per bank, up to 4 GB [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, p. 5-7)]
  * Five 64-bit PCI slots and one slot shared between 64-bit PCI and 16-bit ISA; slot 1 takes half-length cards only [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, p. 5-11)]
  * A combination IDE CD-ROM and floppy drive, one half-height removable media bay, and a disk cage holding either four 1.6-inch or six 1-inch hot swap drives
  * Two 375 W power supplies with a bay for a third, two serial ports, one parallel port, an Ethernet port, keyboard, mouse, and a USB port that "is not supported"
  * The Linux boot log in the manual shows the rest of the onboard hardware: an SMC37c669 Super I/O, two DS21142/3 Tulip Ethernet controllers, and the ATAPI CD-ROM on ''ide0'' [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, pp. 4-21 to 4-23)]

==== SCSI ====

  * "The original DP264/DS20 motherboards were designed with the Adaptec 7895 (?) dual-channel SCSI controller built into the motherboard. We discovered some problems with using it that has forced us to disable it." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1999-May.mbox#L41852|"Re: DS20 Q"]], Jay Estabrook, axp-list, 18 May 1999)]
  * "There were two backplanes for the DS20E, one 4 x ULTRA-2, the other one 6 x ULTRA-3". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2003-July.mbox#L7150|"Re: Hardware question: AS1200, SRM, LSI 53c1010"]], Jay Estabrook, debian-alpha, 12 Jul 2003)] The DS20E and DS25 "have integrated Adaptec SCSI controllers", so their installation avoids the ''qla1280'' firmware problem of the Debian installer. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2019-July.mbox#L1737|"Re: systemd woes continue"]], Frank Scheiner, debian-alpha, 17 Jul 2019)]

==== Linux ====

  * See [[hardware:systems#tsunami_systems|Tsunami Systems]] for notes shared with the other Tsunami machines.
  * Compaq documented Linux alongside Tru64 UNIX and OpenVMS in the DS20E reference guide, with a boot procedure for Red Hat 6.2, SuSE 6.4, and TurboLinux 6.0, and a full boot log of a 2.2.14 SMP kernel built by Jay Estabrook. It calls for SRM V5.6-3 or higher to install Linux, and points at ''http://www.compaq.com/alphaserver/linux'' for the installation document. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_reference_guide.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Reference Guide}}, pp. 4-20 to 4-23)] The release notes give the minimum revisions as Red Hat Distribution 5.2 with SRM V5.5-9 on EV6 or V5.6-3 on EV67. [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_release_notes.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Release Notes}}, April 2000, p. 1)]
  * The USB port and the integrated Adaptec controller appear in the SRM ''show config'' display but are not supported by Tru64 UNIX V4.0F or OpenVMS; a false ''IIC bus Status (01) error'' on power-up "can safely be ignored". [(>{{wiki:hardware:systems:alphaserver_ds20:alphaserver_ds20e_release_notes.pdf?linkonly|AlphaServer DS20E / AlphaStation DS20E Release Notes}}, pp. 1-3)]
  * The XP1000, DS20, and Miata GL share a Cypress IDE quirk, fixed in Jay Estabrook's 2008 kernels: "The problem on CYPRESS IDE machines (XP1000, DS20, MIATA) is fixed." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2008-January.mbox#L289|"My lucky day"]], Jay Estabrook, axp-list, 9 Jan 2008)]

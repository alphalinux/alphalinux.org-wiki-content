The CS20 is a 1U dual processor 21264 server designed by Alpha Processor, Inc., later API NetWorks, and the DS20L is Compaq's version of it. Apart from the front cover, the two differ only in their SRM firmware and the SCSI controller on the PCI riser card. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2002-July.mbox#L17774|"Re: API / CS20"]], Kurt A. Ludwig, axp-list, 29 Jul 2002)] The kernel support was added by Christopher C. Chimelis in 2001, as a variant of the DP264 platform. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_dp264.c?h=v6.10|arch/alpha/kernel/sys_dp264.c]], Linux 6.10)]

==== Specifications ====

API's specification for the CS20, as posted in 2000: [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-November.mbox#L7232|"CS-20 Dual 21264 1U server"]], Bill Broadley, axp-list, 3 Nov 2000, quoting API's web site)]

  * Two 667 MHz [[wp>Alpha_21264#Alpha_21264A|21264A]] or 833 MHz [[wp>Alpha_21264#Alpha_21264B|21264B]] CPUs with 4 MiB of DDR L2 cache each
  * 2.65 GB/s peak main memory bandwidth
  * Two 64-bit 33 MHz PCI slots
  * Onboard Ultra3 SCSI (Symbios 53c1000)
  * Linux in the boot flash ROM
  * 1U rackmount

The CS20 has two independent PCI buses, with most onboard devices on bus 0, so demanding cards perform better on the second bus. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2003-January.mbox#L10816|"Re: matroxfb on SMP alpha"]], Peter Petrakis, debian-alpha, 24 Jan 2003)]

==== Firmware ====

If the DS20L environment variable ''sysvar'' is set to 5, it must be set to 12 and the console re-initialized before the firmware update utility is run, then reset to 5 and re-initialized after the update. [(>{{wiki:software:firmware:alphaserver_ds20l_v6.6_firmware_release_notes.pdf?linkonly|AlphaServer DS20L V6.6 Console Firmware Release Notes}}, December 2003, p. 6)]

==== Linux ====

Current kernels support the Shark as a variant of the DP264 platform. See also [[hardware:systems#tsunami_systems|Tsunami Systems]].

===== AlphaServer DS20L and API NetWorks CS20 (Shark) =====

The CS20 is a 1U dual processor 21264 server designed by Alpha Processor, Inc., later API NetWorks, and the DS20L is Compaq's version of it. "API made the CS20 and CPQ/HP made the DS20L based on it. The only differences between them (besides the front cover) are the SRM and the SCSI controller on the PCI riser card." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2002-July.mbox#L17774|"Re: API / CS20"]], Kurt A. Ludwig, axp-list, 29 Jul 2002)] The kernel support was added by Christopher C. Chimelis in 2001, as a variant of the DP264 platform. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_dp264.c?h=v6.10|arch/alpha/kernel/sys_dp264.c]], Linux 6.10)]

==== Specifications ====

API's specification for the CS20, as posted in 2000: [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-November.mbox#L7232|"CS-20 Dual 21264 1U server"]], Bill Broadley, axp-list, 3 Nov 2000, quoting API's web site)]

  * Two 667 or 833 MHz [[wp>Alpha_21264|21264]] CPUs with 4 MiB of DDR L2 cache each
  * 2.65 GB/s peak main memory bandwidth
  * Two 64-bit 33 MHz PCI slots
  * Onboard Ultra3 SCSI (Symbios 53c1000)
  * Linux in the boot flash ROM
  * 1U rackmount

A CS20 with two 833 MHz CPUs and 4 MiB of DDR cache cost about $14,999 in 2000, without memory or disks. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/2000-November.mbox#L9828|"Re: API Networks article on The Register"]], Maurice Hilarius, axp-list, 6 Nov 2000)]

"The CS20 has independent PCI busses with the bulk of our features hanging off bus zero", so demanding cards "will perform better on the second bus." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2003-January.mbox#L10816|"Re: matroxfb on SMP alpha"]], Peter Petrakis, debian-alpha, 24 Jan 2003)]

==== Firmware ====

Before updating the DS20L firmware, "If you have the environment variable "sysvar" set to 5 then you must set it to 12 and re-initialize before the update utility is run. After updating the firmware, reset sysvar to 5 and re-initialize before booting your operating system." [(>{{wiki:software:firmware:alphaserver_ds20l_v6.6_firmware_release_notes.pdf?linkonly|AlphaServer DS20L V6.6 Console Firmware Release Notes}}, December 2003, p. 6)]

==== Linux ====

On a DS20L, "2.4.27-2-smp works nicely but requires the eepro100 driver instead of the e100 driver", "2.6.8 does not work with either", and "2.6.10-1-smp works with both". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2005-May.mbox#L13222|"fyi - DS20L; NICs,  2.6.8 not so happy; 2.6.10 better"]], Dan Cernese, debian-alpha, 27 May 2005)] See also [[hardware:systems#tsunami_systems|Tsunami Systems]].

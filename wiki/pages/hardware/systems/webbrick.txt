The DS10 is a single processor 21264 server in a 3U rack-ready or desktop enclosure, with Tsunami core logic and a single PCI bus. [(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_brochure.pdf?linkonly|Compaq AlphaServer DS10}}, Compaq, June 1999, p. 6)] [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_dp264.c?h=v6.10|arch/alpha/kernel/sys_dp264.c]], Linux 6.10)] The XP900 is a rebadged DS10 aimed at the OpenVMS workstation market. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2000-October.mbox#L981|"Re: Debian on XP900?"]], David Huggins-Daines, debian-alpha, 12 Oct 2000)] The DS10L is a 1U version with the same CPU speeds and memory capacity, but room for one disk to the DS10's four, and one PCI slot to the DS10's four. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2003-November.mbox#L3445|"Re: Seeking opinion on DS10 veersus DS10L"]], Jay Estabrook, axp-list, 19 Nov 2003)]

==== Specifications ====

=== AlphaServer DS10 ===

[(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_brochure.pdf?linkonly|Compaq AlphaServer DS10}}, Compaq, June 1999, p. 6)]

  * One [[wp>Alpha_21264|21264]] with 2 MiB of L2 cache: a 466 MHz 21264 (EV6) [(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_466_mhz_quickspecs.pdf?linkonly|Compaq AlphaServer DS10 (466 MHz) and AlphaStation DS10 (466 MHz) QuickSpecs}}, p. 2)] or, in later models, a [[wp>Alpha_21264#Alpha_21264A|21264A]] (EV67) sold as 600 MHz [(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_quickspecs.pdf?linkonly|Compaq AlphaServer DS10 and AlphaStation DS10 QuickSpecs}}, p. 3)]. The 600 MHz model actually runs at 617 MHz, and its console and operating systems identify it as the "DS10 617 MHz" [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/netbsd-port-alpha-mbox/gmane-2007-August.mbox#L1412|"Occasional stops / DMA errors on a DS10"]], Torsten Harenberg, port-alpha, 25 Aug 2007)] [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/comp-unix-tru64-mbox/googlegroups-2012-January.mbox#L273|"Re: AlphaServer DS10 470 MHz?"]], Marc Schlensog, comp.unix.tru64, 22 Jan 2012)]
  * The DS10L was sold with the same two CPUs: a 466 MHz 21264 [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/netbsd-port-alpha-mbox/gmane-2005-December.mbox#L1620|"DS10L -- missing IDE interrupts?"]], Havard Eidnes, port-alpha, 24 Dec 2005)] or a 600 MHz 21264A, each with 2 MiB of cache [(>{{wiki:hardware:systems:alphaserver_ds10l:alphaserver_ds10l_quickspecs.pdf?linkonly|Compaq AlphaServer DS10L QuickSpecs}}, p. 2)]
  * 21272 (Tsunami) core logic with 128-bit wide memory datapaths and a crossbar switch, 1.3 GB/s peak memory bandwidth
  * Up to 2 GiB of ECC 100 MHz SDRAM DIMMs, with ECC on memory and processor cache
  * Four PCI slots: three 64-bit and one 32-bit
  * IDE storage, or SCSI with an optional PCI adapter; the IDE controller is part of the ALi M1543C multi-I/O chip [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-August.mbox#L52462|"Re: DS10's"]], Ivan Kokshaysky, axp-list, 31 Aug 1999)]
  * Two onboard 21143 (Tulip) 10/100 Ethernet controllers [(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_technical_summary.pdf?linkonly|Compaq AlphaServer DS10 Systems Technical Summary}}, p. 8)]
  * Five drive bays (floppy, CD-ROM, and three open), 300 W power supply
  * Two serial ports, one parallel port, keyboard and mouse
  * Auto reboot, thermal management, remote system management, memory failover, error logging

=== AlphaStation XP900 ===

The XP900 has the same 466 MHz 21264 with 2 MiB of L2 cache and the same memory limit, but leaves up to two PCI slots available and adds 2D and 3D graphics support including multi-head, and audio. It was sold for OpenVMS. [(>{{wiki:hardware:systems:alphastation_xp900:alphastation_xp900_product_profile.pdf?linkonly|Compaq AlphaStation XP900 Alpha 21264 Processor}}, Product Profile, Compaq, June 1999)]

==== Firmware ====

Use the final SRM version, V7.3-1 (see [[software:firmware:srm#final_versions|final SRM versions]]). Linux boots from SRM with aboot, although the XP900 console reference names AlphaBIOS as the console for Windows NT and Linux. [(>{{wiki:hardware:systems:alphastation_xp900:alphastation_xp900_console_reference.pdf?linkonly|AlphaStation XP900 Console Reference}}, EK-DS10V-CR.A01, title page)]

  * The console numbers the PCI slots differently from the chassis: logical slots 14 to 17 are physical slots 0 to 3, counting from the bottom, and the bottom slot is the 32-bit one. [(>{{wiki:hardware:systems:alphastation_xp900:alphastation_xp900_console_reference.pdf?linkonly|AlphaStation XP900 Console Reference}}, pp. 1-4 to 1-5, 2-11)] Onboard, the two Ethernet controllers, which the console reports as DE500-BA, are on bus 0 slots 9 and 11 and the Acer Labs M1543C IDE (''dqa'' and ''dqb'') on slot 13. [(>{{wiki:hardware:systems:alphastation_xp900:alphastation_xp900_console_reference.pdf?linkonly|AlphaStation XP900 Console Reference}}, p. 1-4)]
  * The remote management console is reached with <key>Esc</key> <key>Esc</key> ''rmc'', of which only the "MC" is echoed. [(>{{wiki:hardware:systems:alphastation_xp900:alphastation_xp900_release_notes.pdf?linkonly|AlphaStation XP900 Release Notes}}, EK-DS10V-RN.A01, August 1999)]

==== Linux ====

Current kernels support these systems (''CONFIG_ALPHA_DP264'', or a generic kernel), which boot from SRM with aboot. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_dp264.c?h=v7.3-rc1|arch/alpha/kernel/sys_dp264.c]], Linux 7.3)] SRM can boot Linux from the onboard IDE disk and CD-ROM. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/1999-July.mbox#L19640|"Re: DS10 EIDE Disk"]], Jay Estabrook, axp-list, 15 Jul 1999)] The onboard 21143 Ethernet controllers use the ''tulip'' driver and the ALi M1543C IDE controller the ''pata_ali'' driver. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/net/ethernet/dec/tulip/tulip_core.c?h=v7.3-rc1|drivers/net/ethernet/dec/tulip/tulip_core.c]], Linux 7.3)] [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/ata/pata_ali.c?h=v7.3-rc1|drivers/ata/pata_ali.c]], Linux 7.3)] See also [[hardware:systems#tsunami_systems|Tsunami Systems]].

The DS10L has the same onboard devices: its console lists the two Ethernet controllers as DE500-BA and the Acer Labs M1543C IDE, and its single PCI slot is logical slot 17. [(>{{wiki:hardware:systems:alphaserver_ds10:alphaserver_ds10_ds10l_console_reference.pdf?linkonly|AlphaServer DS10/DS10L and AlphaStation DS10 Console Reference}}, p. 1-7)] Graphics are an option on the DS10L, [(>{{wiki:hardware:systems:alphaserver_ds10l:alphaserver_ds10l_quickspecs.pdf?linkonly|Compaq AlphaServer DS10L QuickSpecs}}, p. 21)] and would occupy that one slot; a serial console leaves it free. The DS10L's COM1 port is both the RMC port and an ordinary serial port. [(>{{wiki:hardware:systems:alphaserver_ds10l:alphaserver_ds10l_quickspecs.pdf?linkonly|Compaq AlphaServer DS10L QuickSpecs}}, p. 1)] For serial console setup, see [[documentation:srm#serial_console|Using SRM]].

Debian Ports installed on a DS10L from both its network and CD images in 2015, [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2015-March.mbox#L418|"Re: Pre-DEBIAN 8.0 install images for ALPHA architecture (debian-ports unstable release)"]], Bill MacAllister, debian-alpha, 4 Mar 2015)] and a DS10 was running Debian in 2024. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2024-March.mbox#L1608|"Mounting ODS-2 drive in Debian?"]], David J Novak, debian-alpha, 22 Mar 2024)]

==== Known issues ====

  * **Large disks:** the DS10L's IDE controller, in the ALi M1543C A1 southbridge, is Ultra-33 with 28-bit LBA; Tru64 UNIX could use only the first 128 GiB of a 250 GB disk that SRM V7.3-1 listed correctly. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/tru64-unix-managers-mbox/gmane-2008-May.mbox#L814|"SUMMARY: alpha DS10L and large IDE disk"]], Stoyan Angelov, tru64-unix-managers, 18 May 2008)] Linux's ''pata_ali'' driver issues the 48-bit commands needed beyond 128 GiB by PIO on these controllers, so the whole disk is usable, with slower access to the part above 128 GiB. [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/ata/pata_ali.c?h=v7.3-rc1|drivers/ata/pata_ali.c]], Linux 7.3)]
  * **Noise and cooling:** the DS10L's fans are too loud for an office, [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/axp-list-mbox/2003-November.mbox#L3445|"Re: Seeking opinion on DS10 veersus DS10L"]], Jay Estabrook, axp-list, 19 Nov 2003)] and its cooling capacity is limited. [(>[[https://github.com/alphalinux/mailing-list-archives/blob/main/debian-alpha-mbox/2005-July.mbox#L11968|"Re: DS10L overcloking"]], Jay Estabrook, debian-alpha, 27 Jul 2005)]

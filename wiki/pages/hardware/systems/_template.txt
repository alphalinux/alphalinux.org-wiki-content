One or two sentences: what the system is, who sold it, and when. Cite a source for each fact. Keep Linux support out of the introduction; it goes in the Linux section.

Delete any infobox row whose value has no source, except Kernel option, which is "None" for systems that no kernel ever supported. The Linux row takes one of these values, the same as in the [[hardware:systems|Systems]] table:

  * **Supported:** current kernels support the system.
  * **Linux 6.9 and earlier:** Linux 6.10 removed support for the system's processors.
  * **Untested:** current kernels contain support for the system, but no one has reported booting a current kernel on it, or there is a specific reason for doubt, such as a system that only MILO can boot.
  * **Never:** no Linux kernel has supported the system.

A system sold with both older processors and the EV56 (21164A) or later qualifies the value, for example "Supported (21164A models); others Linux 6.9 and earlier".

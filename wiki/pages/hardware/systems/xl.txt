===== Alpha XL 233 and 266 =====

The Alpha XL 233 and 266 are Windows NT workstations with EV4 or EV45 CPUs. "The internal name for those boxes was "NT Dream Machine"". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1998-January.mbox#L26311|"Re: Does DEC have a clue?"]], Jay Estabrook, axp-list, 21 Jan 1998)] "The 233/266 versions, with EV4/EV45 CPUs will have *only* ARC console. There actually *was* an AlphaBIOS for the 233/266, but it never shipped". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-November.mbox#L46358|"Re: DEC Celebris"]], Jay Estabrook, axp-list, 25 Nov 1996)] The EV5 Alpha XL 300, 366, and 433 are a different design (see [[hardware:systems:alcor|XLT]]).

Digital announced the Alpha XL on 3 October 1995 as the Alpha half of a Windows NT personal workstation line alongside the Pentium-based Celebris XL. Both use the same minitower and a processor-independent CPU daughtercard, so that the rest of the machine is common to the Pentium and Alpha models. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/biz-digital-articles-mbox/googlegroups-1995-October.mbox#L4845|"Celebris XL & Alpha XL -- Digital Personal Workstation for Windows NT"]], Customer Update, biz.digital.articles, 3 Oct 1995)]

==== Specifications ====

  * [[wp>Alpha_21064|21064]] or [[wp>Alpha_21064#Alpha_21064A|21064A]] at 233 or 266 MHz, with APECS core logic and an Intel SIO PCI-to-ISA bridge, which the kernel handles together with the Avanti and Noname machines [(>[[https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/arch/alpha/kernel/sys_sio.c?h=v6.10|arch/alpha/kernel/sys_sio.c]], Linux 6.10)]
  * PCI and ISA, with an Intel 82379AB PCI-to-ISA bridge; the closely related [[hardware:systems:avanti|Avanti]] machines use an 82378IB or 82378ZB instead, which is how the two are told apart [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-March.mbox#L6843|"Alpha XL Support"]], Jay Estabrook, axp-list, 22 Mar 1996)]
  * ARC console only; MILO is used to boot Linux [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1997-October.mbox#L20901|"Re: Milo booting other OSes?"]], Jay Estabrook, axp-list, 29 Oct 1997)]
  * Machines have been reported with 192 MiB of memory [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-hardware-mbox/2000-May.mbox#L1|"Alpha XL266"]], AzRaeL, axp-hardware, 4 May 2000)]

==== Linux ====

Linux 6.9 was the last version to support the XL; see [[hardware:systems|Systems]].

  * "XL kernels and MILO will run on XL-233/266 as well as AVANTI", but not the reverse. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-November.mbox#L48090|"Re: XL or Avanti?"]], Jay Estabrook, axp-list, 26 Nov 1996)] With an Avanti kernel, "the floppy drive (on the XL) cannot DMA to all of CPU memory". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1997-December.mbox#L30289|"Re: Can't load RAMDISK on XL-266"]], Jay Estabrook, axp-list, 23 Dec 1997)]
  * With a Matrox Millennium, "you MUST be running an XL kernel, *NOT* an AVANTI one". [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1998-June.mbox#L34116|"Re: XL266: MILO/SCSI problem, X I/O problem"]], Jay Estabrook, axp-list, 17 Jun 1998)]

==== Graphics ====

Cards recommended for X on the XL in 1996 included Number 9, Mach64, and Digital ZLXp (TGA) cards, [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-April.mbox#L11197|"RE: Which graphics accelerator should one use for Linux-Alpha XL266?"]], David Rusling, axp-list, 23 Apr 1996)] and most PCI S3-based cards. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-April.mbox#L11197|"RE: Which graphics accelerator should one use for Linux-Alpha XL266?"]], David Rusling, axp-list, 23 Apr 1996)] as well as "Almost any PCI bus S3-based card, ie Diamond Stealth 64, #9 GXE64, ELSA, etc." [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/axp-list-mbox/1996-April.mbox#L11271|"Re: Which graphics accelerator should one use for Linux-Alpha XL266?"]], Jay Estabrook, axp-list, 23 Apr 1996)] See also [[hardware:other#pc_graphics_cards|Other Hardware]].

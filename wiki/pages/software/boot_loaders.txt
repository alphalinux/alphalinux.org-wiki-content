===== Boot Loaders =====

Which boot loader an Alpha system uses depends on its [[software:firmware|firmware]]. Almost every Alpha that runs Linux today boots it with [[software:boot_loaders:aboot|aboot]] from the SRM console. [[software:boot_loaders:milo|MILO]] is needed only on the few systems without SRM, such as the Alpha XLT and the AlphaPC 164UX (Ruffian); no released MILO binary boots a current kernel, so it must be built from the [[https://github.com/alphalinux-org/milo|alphalinux-org/milo]] repository. Under [[software:emulators#qemu|QEMU]], no boot loader is used: QEMU loads the kernel and initrd itself. See [[documentation:installation|Installation]] for the complete procedure.

^ Boot loader ^ Firmware ^ Description ^
| [[software:boot_loaders:aboot|aboot]] | SRM console | Loads Linux from a disk, CD, or the network, using the console's PALcode and services |
| [[software:boot_loaders:milo|MILO]] | ARC, AlphaBIOS, ARCSBIOS | Miniloader that provides its own PALcode and device drivers, loaded through ''linload.exe'' or ''ldmilo.exe''; last released in 2001, so current kernels need a MILO built from source |
| APB | AlphaBIOS on the [[hardware:motherboards:up1000|UP1000]] | Loaded by AlphaBIOS; reads the AlphaBIOS boot configuration to find the kernel [(>{{wiki:hardware:motherboards:up1000:up1000_user_manual.pdf?linkonly|UP1000 User Manual}}, pp. 4-14 to 4-15)] |
| None | qemu-palcode, under [[software:emulators#qemu|QEMU]] | QEMU loads the kernel and initrd given with ''-kernel'' and ''-initrd''; see [[documentation:qemu|QEMU]] [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2021-March.mbox#L470|"Bug#986009: installation-reports: document qemu workarounds and bug in newer d-i image (fwd)"]], Thorsten Glaser, debian-alpha, 27 Mar 2021)] |

The SRM console can also boot a Linux kernel directly over the network with BOOTP, without a boot loader, using an image built with the kernel's ''bootpfile'' or ''bootpzfile'' target. [(>[[https://github.com/alphalinux-org/mailing-list-archives/blob/main/debian-alpha-mbox/2007-August.mbox#L1139|"Re: [BUG] 2.6.23-rc3 won't boot on alpha (fwd)"]], Jay Estabrook, debian-alpha, 16 Aug 2007)] See [[software:boot_loaders:aboot#network_booting|aboot: Network booting]].
